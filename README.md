Task Management Application

A Full Stack Task Management Application built using the MERN Stack.

Features

- User Authentication (JWT)
- Register & Login
- Forgot Password with OTP
- Reset Password
- Create, Edit & Delete Tasks
- Task Calendar
- Notifications
- Task Analytics
- PDF Export
- Responsive Design

Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- Resend API

Installation

```bash
git clone https://github.com/Gurudatta2212/task-management-app.git
```

Client

```bash
cd client
npm install
npm run dev
```

Server

```bash
cd server
npm install
npm run dev
```

Environment Variables

Server

```env
MONGODB_URI=
JWT_SECRET=
RESEND_API_KEY=
```

Client

```env
VITE_API_URL=
```
